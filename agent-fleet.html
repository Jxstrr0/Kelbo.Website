Agent Fleet

A set of small, single-purpose bots I can run from my phone, like news digests, trackers, and weekly scans. It's still in the planning stage, so this page is the plan.

The idea

Instead of one big AI app that tries to do everything, Agent Fleet is a handful of small bots that each do one job. Each one runs on a schedule or when I tap a button, then sends back a short report I can read on my phone.

Why build it

  • Most of my day is on my phone, so the bots need to work from there.
  • A lot of what I check every day is the same routine: the news, the stocks I'm watching, my own trading record. That's the kind of work worth handing off.
  • Small bots are easier to build, test, and fix one at a time. If one breaks, the rest keep running.

First bots on the list

Ideas for now. None of these are built yet.

  • News digest

    Idea

    A short summary before the open of the news that matters for the stocks I'm watching, so I'm not scrolling five apps to find it.

  • Trade tracker

    Idea

    Reads my trading journal and options record and points out patterns, like a run of losses or trades taken on wide spreads.

  • Weekly scan

    Idea

    Every weekend, a look at which stocks moved most and what's coming up next week, like earnings and big economic reports.

How it'll work

The bots will need AI and market data services, and those need private keys. This site is public, so the keys can't live here. The bots will run somewhere separate that keeps the keys safe, and this page will show what's live once they're running.
