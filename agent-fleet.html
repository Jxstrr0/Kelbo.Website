Agent Fleet

A set of small, single-purpose bots I can run from my phone, like news digests, trackers, and weekly scans. The weekly scan is the first one running. The rest are still the plan.

The idea

Instead of one big AI app that tries to do everything, Agent Fleet is a handful of small bots that each do one job. Each one runs on a schedule or when I tap a button, then sends back a short report I can read on my phone.

Why build it

  • Most of my day is on my phone, so the bots need to work from there.
  • A lot of what I check every day is the same routine: the news, the stocks I'm watching, my own trading record. That's the kind of work worth handing off.
  • Small bots are easier to build, test, and fix one at a time. If one breaks, the rest keep running.

How it'll work

The weekly scan runs as a scheduled task on my own Claude plan. Once a week it reads the market news, writes the scan into this site and publishes it, so there are no API keys involved.

Bots that need to run more often, or pull from paid market data, will need private keys. This site is public, so those keys can't live here. They'll run somewhere separate that keeps the keys safe.
